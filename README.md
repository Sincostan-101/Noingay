# Nói Ngay

Web học **giao tiếp** tiếng Anh và tiếng Trung theo tình huống, dành cho người Việt.

Mỗi bài có 4 bước: nghe hội thoại → nói câu then chốt (chấm phát âm) → đóng vai → "Vì sao nói vậy?".

- Chạy hoàn toàn trên trình duyệt, không cần máy chủ.
- Giọng đọc và nhận giọng nói dùng Web Speech API của trình duyệt (nên dùng Chrome hoặc Edge).
- Tiến độ học lưu trên máy người học (localStorage).
